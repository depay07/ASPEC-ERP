# 계약서 관리

ERP 왼쪽 메뉴의 **계약서 관리 → 계약서 등록**에서 계약명, 거래처, 계약일, 메모를 작성하고 서면 계약서의 스캔본을 첨부합니다. 계약명만 필수이며, 계약 정보를 먼저 등록한 뒤 나중에 스캔본을 추가할 수도 있습니다. 거래처는 기존 거래처 목록에서 선택하거나 직접 입력할 수 있습니다.

- PDF, JPG/JPEG, PNG를 여러 장 첨부할 수 있습니다. 파일당 최대 50 MiB, 계약서당 30개입니다.
- 등록한 스캔본은 미리보기와 다운로드가 가능합니다. 실제 브라우저의 PDF/이미지 뷰어를 이용합니다.
- 제목·거래처·메모로 검색합니다. 50건씩 페이지를 나눠 모든 계약서를 조회합니다.
- 계약서는 **보관**하면 보관함으로 이동하고 **복원**하면 다시 수정할 수 있습니다. 스캔본은 유지됩니다.
- 잘못 첨부한 스캔본은 확인 후 개별 삭제할 수 있습니다. 계약 자체를 영구 삭제하는 기능은 제공하지 않습니다.
- 업로드 일부가 실패하면 계약 정보와 완료된 파일은 남기고, 미완료 파일만 다시 저장합니다. 동일 업로드 ID의 재시도로 파일을 중복 생성하지 않습니다.
- 다른 창에서 계약 정보가 바뀌었으면 기존 내용으로 덮어쓰지 않고 다시 열도록 안내합니다.

## 저장 및 접근

기존 Oracle 파일클라우드 API와 직원 허용 목록을 이용합니다. **로그인한 본인 계정의 계약서만 접근**할 수 있습니다. 계약서 스캔본은 일반 파일클라우드 목록·검색·공유 코드에 나타나지 않습니다. 동료 간 계약서 공유 기능은 포함하지 않았습니다.

메타데이터는 기존 `/data/aspec-cloud/meta/cloud.sqlite`의 `contracts`, `contract_files`에 저장합니다. 파일은 `/data/aspec-cloud/contracts/<UUID>`에 저장하며, 원본 파일명은 물리 경로로 사용하지 않습니다. Supabase에는 테이블·버킷·권한 변경이 없습니다. 파일명 확장자와 파일 헤더를 함께 확인하며, 전문 악성코드 검사는 하지 않습니다.

첨부 접근은 기존 `/cloud/download-session`으로 본인 소유를 확인하고, 한 파일에 묶인 90초 HttpOnly/Secure 쿠키로만 열 수 있습니다. URL에 ERP 로그인 토큰이 노출되지 않습니다. 미리보기도 동일한 인증을 거칩니다. 로그아웃 시 쿠키가 폐기됩니다.

단일 파일 업로드를 스트리밍 처리합니다. 50 MiB 전체를 메모리에 올리지 않습니다. 네트워크가 끊기면 불완전한 파일을 제거하며 재시도 시 처음부터 전송합니다. 프로세스 재시작 때 메타데이터가 없는 중단 파일을 정리합니다. 대용량 파일의 브라우저 종료 후 조각 이어받기는 이 메뉴에 포함하지 않았습니다.

## 배포와 검증

`sudo bash install.sh --update-only`로 기존 서비스·디스크 설정은 유지하면서 API 파일과 Nginx의 계약서 업로드 경로(50 MiB 한도)를 추가합니다. `contracts.mjs` 및 `contracts.test.mjs`를 배포 패키지에 포함해야 합니다. 백엔드를 먼저 배포한 뒤 ERP 소스를 반영합니다.

```sh
node --test aspec-cloud/test.mjs aspec-cloud/contracts.test.mjs 'tests/*.test.cjs'
```

계약서 생성·검색·수정 충돌·비공개 미리보기·소유자 분리·일반 클라우드 및 공유 차단·파일 형식 검증·보관/복원·재시작·페이지 조회와 부분 업로드 실패 재시도를 검증합니다. 테스트는 격리된 임시 디렉터리와 가짜 인증을 사용하며 실제 업무 계약서를 만들거나 삭제하지 않습니다.

2026-11-08 검증: 위 명령의 테스트 62개 통과. 운영 서버에서도 격리 테스트 6개를 실행하고 배포했습니다. Nginx 구문 검사, 서비스 상태, HTTPS 인증 차단(401), 첨부 CORS와 10 MiB 요청의 업로드 경로 통과를 확인했습니다. 브라우저에서는 예시 데이터로 목록·등록·저장 화면을 확인했습니다. 실제 계정의 업무 계약서나 스캔본으로 등록 테스트를 하지는 않았습니다. 배포 전 코드·설정 백업은 `/opt/aspec-cloud/releases/20261108-111128`입니다.
