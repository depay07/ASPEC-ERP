## 남은 설정 및 운영 참고

- Supabase의 유출 비밀번호 차단 기능은 비활성 상태로 남아 있다. 현재 연결 도구에는 해당 Auth 설정 변경 기능이 없어 변경하지 않았다. [Supabase 비밀번호 보안 문서](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection) 및 프로젝트의 Auth 설정에서 지원 여부와 활성화를 확인한다.
- 두 공유 문서 RPC에 대한 SECURITY DEFINER 경고는 의도된 공개 토큰 조회 경계다. 고정 search_path, 정확한 토큰 조건, 명시적 필드 목록으로 제한했다. 전체 테이블 공개 정책으로 되돌리면 안 된다.
- `private.erp_staff`의 RLS 정책 없음 알림은 의도적인 기본 거부 상태다. 일반 계정에는 테이블 권한을 부여하지 않으며, 제한된 내부 함수가 현재 계정의 명부 포함 여부만 반환한다.
- 사용되지 않는 `erp-files` 버킷은 기존 설정을 유지했다. 확인 시 파일은 0개였다.
- 새 직원은 Supabase 관리자 권한으로 `private.erp_staff`에 승인된 UUID를 추가해야 한다. 사용자 가입만으로 접근 권한이 생기지 않는다.
- 60초 서명 URL은 유효 시간 동안 소지자가 열 수 있다. 이미 다운로드된 파일이나 브라우저에 표시된 자료를 소급 회수하지는 않는다.
